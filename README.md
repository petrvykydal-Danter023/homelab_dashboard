# Vykylab · Homelab Dashboard

Minimalistický rodinný a administrátorský dashboard pro správu domácího serveru.

## Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Vite (`frontend/`)
- **Backend:** Rust, Axum, Tokio, Sysinfo (`backend/`)

## Spuštění
```bash
# Backend (http://127.0.0.1:3001)
cd backend && cargo run

# Frontend (http://localhost:5173)
cd frontend && npm run dev
```
